# Projection improvement priorities

Current production architecture remains unchanged.

1. Verify current-week injury reports and quarterback availability against dated official reports; retain uncertainty when reports are unavailable.
2. Refresh lagging Dallas and Philadelphia coverage inputs in a new prospective version, preserving the published Week 8 freeze.
3. Collect weather at the actual kickoff window and verify roof status.
4. Capture posted officiating crews as context; estimate crew effects only after testing shrinkage and out-of-sample stability.
5. Preserve pregame market snapshots, prices and closing lines. Reference odds alone do not support execution or ROI claims.
6. Compare model versions on identical games using margin and total MAE/RMSE, ATS/SU counts and calibration. Keep model selection separate from held-out evaluation.
7. Test injury, weather, situational and outside-rating features as challengers before any promotion.

No new adjustment is claimed as implemented or validated by this document.
